# Tower_defense
2D-игра в жанре Tower Defense на C# с использованием Windows Forms.

Игрок защищает базу от волн противников, размещая защитные башни и улучшая оборону. По мере прохождения планируется добавлять новые типы башен, врагов и игровые механики.
Технологии
- C# / Windows Forms
- Архитектура MVC
- Модульное тестирование игровой логики
